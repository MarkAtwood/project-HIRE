# Code of Conduct

This project follows the [CNCF Community Code of Conduct
v1.3](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). It is
adopted by reference rather than copied, so it stays current when CNCF revises
it.

**Reporting.** Send reports to the maintainer listed in
[MAINTAINERS.md](MAINTAINERS.md). That is the whole process today, and it is
worth being plain about what that means: the maintainer is one person, reports
go to them directly, and there is no committee to escalate to if the complaint
is about them.

The CNCF Code of Conduct names `conduct@cncf.io` as its reporting address. That
committee handles CNCF projects, and HIRE is not one -- see
[UPSTREAM.md](UPSTREAM.md). Sending a report there today would reach people with
no standing to act on it. If HIRE is ever accepted into CNCF, that address
becomes the escalation path and this file will say so.
